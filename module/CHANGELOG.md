# 更新日志

> v1.7.9：新增「关于我们」更新日志入口；支持在线更新（update.json）。

## v1.7.8（2026-11-04）
- **修复游戏检测悖论**：原来判断「前台是不是游戏」，导致切到 WebUI 查看配置时必然显示「未检测到游戏」。
  现改为只看「游戏进程是否在运行」，与前台无关。
- **修复游戏层频率上限未解除**：`[ -w ]` 对 `/proc` 伪文件误判导致跳过，改为直接写入。
- **核频显示改为「上限 / 满频」**（如 `1843 / 3187M`）：被压标黄、满频标绿，一眼看出有没有被限频。
- 面板打开时显示「读取中」，不再先闪默认值。

## v1.7.7（2026-11-04）
- 修复「保存选择」后应用选择弹窗不关闭的问题。
